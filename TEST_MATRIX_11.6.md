# Ручная проверка 11.6.1 перед публикацией

## Минимальные устройства

1. Основная Android TV-приставка пользователя.
2. Устройство с Yandex WebView.
3. Телефон/планшет Android с системным Chrome WebView.
4. По возможности слабая приставка с Android 9–11.

## Загрузка плеера

- Открыть фильм и сериал через поиск.
- Проверить оболочки `villybizy.best` и `villybizy.skin`.
- Убедиться, что служебный HTTP 404 не оставляет чёрную плашку.
- Проверить появление iframe `theatre.stravers.live`.
- Повторить после кнопки «Обновить плеер».

## Оконный режим

- Клик по центральной области: один toggle, без двойного переключения.
- Media Play/Pause на пульте: один toggle.
- Air-mouse: OK работает только при фокусе на WebView.
- После ухода в меню OK не должен кликать по старым координатам.

## Fullscreen

- Открыть fullscreen штатной кнопкой плеера.
- Нажать Play/Pause на пульте.
- Нажать DPAD_CENTER/Enter.
- Кликнуть по видео air-mouse.
- Кликнуть по штатным кнопкам плеера.
- Убедиться, что одно действие не даёт двойного toggle.
- Выйти Back и повторно войти в fullscreen.

## Обновление

- Скачать APK: после 100% появляется «Обновление скачано».
- Нажать «Позже», затем снова «Обновить»: повторной загрузки быть не должно.
- Нажать «Установить» и отменить системный установщик: он не должен открыться сам повторно.
- APK с другой подписью должен быть отклонён приложением.

## Диагностика

- QR и ссылка открываются с телефона в той же сети.
- Ссылка недоступна через другой сетевой интерфейс устройства.
- Через 10 минут сервер прекращает работу.
